# Document and Artifact Reliability Protocol

## Contract

Capture:
- audience;
- purpose;
- required sections;
- required format;
- source materials;
- style/brand constraints;
- page/length constraints;
- factual claims requiring verification.

## Production

Create against an explicit outline mapped to requirements.

For structured artifacts, verify both:
1. semantic content;
2. rendered/structural integrity.

## Verification

Check:
- required sections present;
- no placeholder text;
- factual claims supported;
- names/dates/numbers consistent;
- tables/charts match source data;
- links/references valid when applicable;
- formatting/rendering not broken;
- output file opens successfully.

## Gauntlet

Search for:
- omitted requirement;
- unsupported claim;
- contradictory numbers;
- duplicated or missing sections;
- accidental template residue;
- inaccessible or malformed output;
- content that is correct in source form but broken when rendered.
